phase-cloud-ring シェーダ実装解説

このドキュメントは cloud/phase-cloud-ring.html の WebGPU シェーダを、 バーテックスシェーダ、フラグメントシェーダ、ノイズ生成、位相雲、表示回転の順に読み解くためのものです。

生成用シェーダ

雲パターンをピクセル単位で計算し、オフスクリーンテクスチャへ描画します。

表示用シェーダ

生成済みテクスチャをサンプリングし、中心を保ったまま表示回転します。

保存用シェーダ

生成用シェーダと同じロジックを使い、現在角度を焼き込んだ正方形 PNG を出力します。

1. 全体の描画パイプライン

このページは、複雑な形状メッシュを作らず、画面全体を覆う三角形を 1 枚だけ描きます。 各ピクセルの色はフラグメントシェーダで直接計算されます。

1. 生成 cloudShader が雲リングを生成し、offscreenTexture に書き込みます。
2. 表示 displayShader が offscreenTexture を読み、現在の表示回転を適用します。
3. アニメーション 自動回転中は雲を再生成せず、表示用テクスチャ座標だけを回転します。

そのため、重い雲生成は Run、再生成、リサイズなどのタイミングに寄せられます。 回転だけなら表示用シェーダのサンプリングで済みます。

2. Uniforms の役割

生成用シェーダには UI からの値が Uniforms として渡されます。 ここに雲の数、半径、サイズ、位相、シード、球面回転軸などが入ります。 

struct Uniforms {
  resolution: vec2f,
  count: f32,
  ringRadius: f32,
  cloudSize: f32,
  cloudAspect: f32,
  cloud: f32,
  swirl: f32,
  paper: f32,
  softness: f32,
  phase: f32,
  phaseCycles: f32,
  rotation: f32,
  seed: f32,
  orientation: f32,
  centerY: f32,
  sphereAxis: vec4f,
  spiralTurns: f32,
  viewScale: f32,
  outerFadeStart: f32,
  outerFadeSpeed: f32,
};
項目 意味
resolution キャンバスのピクセルサイズ。座標正規化に使います。
count, spiralTurns 一周あたりの配置数と巻き数。合計雲数は概ね count * spiralTurns です。
ringRadius 渦巻き配置の外周半径です。
cloudSize, cloudAspect 各雲パーツの縦サイズと横方向倍率です。
cloud, paper ノイズ値を白い墨模様に変換するときの濃度としきい値です。
swirl ノイズ座標を歪ませる量。モヤモヤの流れと渦感に効きます。
phase, phaseCycles 球面雲を回した状態として各雲の見た目を変える位相です。
sphereAxis 位相変化で球面をどの軸の周りに回すかを決めます。
outerFadeStart, softness, outerFadeSpeed 各雲パーツの外縁フェード位置、幅、カーブです。

3. バーテックスシェーダ

生成用と表示用のバーテックスシェーダは同じ考え方です。 頂点バッファを使わず、vertex_index だけで巨大な三角形を 1 枚作ります。 

@vertex
fn vs(@builtin(vertex_index) vertexIndex: u32) -> @builtin(position) vec4f {
  let positions = array<vec2f, 3>(
    vec2f(-1.0, -3.0),
    vec2f( 3.0,  1.0),
    vec2f(-1.0,  1.0)
  );

  return vec4f(positions[vertexIndex], 0.0, 1.0);
}

この 3 点はクリップ空間上で画面全体を覆います。 以降の見た目はすべてフラグメントシェーダ側で決まるため、頂点シェーダは画面を塗るための最小構成です。

4. ノイズ生成

hash

hash は 2D 座標から 0 から 1 の疑似乱数を作ります。 格子点ごとにランダム値を持たせるための基礎関数です。 

fn hash(p: vec2f) -> f32 {
  let h = dot(p, vec2f(127.1, 311.7));
  return fract(sin(h) * 43758.5453123);
}

noise

noise は現在座標が属する格子の 4 隅で hash を呼び、 その値をなめらかに補間します。これでカクカクした乱数ではなく、連続した濃淡になります。 

fn noise(p: vec2f) -> f32 {
  let i = floor(p);
  let f = fract(p);

  let a = hash(i);
  let b = hash(i + vec2f(1.0, 0.0));
  let c = hash(i + vec2f(0.0, 1.0));
  let d = hash(i + vec2f(1.0, 1.0));

  let w = f * f * (3.0 - 2.0 * f);
  return mix(mix(a, b, w.x), mix(c, d, w.x), w.y);
}

fbm

fbm は複数のスケールの noise を足します。 大きなムラと細かいムラを重ねることで、雲や煙に近い階層的な模様になります。 

fn fbm(p0: vec2f) -> f32 {
  var p = p0;
  var amplitude = 0.5;
  var value = 0.0;

  for (var i = 0; i < 6; i = i + 1) {
    value += amplitude * noise(p);
    p = mat2x2f(1.62, 1.11, -1.11, 1.62) * p;
    amplitude *= 0.52;
  }

  return value;
}

座標変換行列 mat2x2f(1.62, 1.11, -1.11, 1.62) は、各オクターブで座標を回転しながら拡大します。 これにより、単純な格子方向の繰り返しが目立ちにくくなります。

5. 生成用フラグメントシェーダ

生成用フラグメントシェーダは、現在ピクセルの正規化座標を作り、渦巻き上に置かれた雲パーツを順番に調べます。 最終的には、すべての雲パーツのうち最も濃い値を採用します。 

@fragment
fn fs(@builtin(position) position: vec4f) -> @location(0) vec4f {
  let tau = 6.28318530718;
  let minResolution = min(u.resolution.x, u.resolution.y);

  var uv = (position.xy * 2.0 - u.resolution) / minResolution;
  uv.y = -uv.y;
  uv -= vec2f(0.0, u.centerY);
  uv *= u.viewScale;

  let countPerTurn = clamp(floor(u.count + 0.5), 1.0, 120.0);
  let spiralTurns = clamp(u.spiralTurns, 1.0, 32.0);
  let totalCount = clamp(ceil(countPerTurn * spiralTurns) + 1.0, 2.0, 4096.0);
  var ink = 0.0;

  for (var i: u32 = 0u; i < 4096u; i = i + 1u) {
    let fi = f32(i);
    if (fi >= totalCount) {
      break;
    }

    ...
    let cloudInk = phaseCloud(local, instancePhase);
    ink = max(ink, cloudInk);
  }

  let paperColor = vec3f(0.0, 0.0, 0.0);
  let inkColor = vec3f(1.0, 1.0, 1.0);
  let color = mix(paperColor, inkColor, clamp(ink, 0.0, 0.98));

  return vec4f(color, 1.0);
}

座標正規化

position.xy はピクセル座標です。 これを短辺基準の座標に変換して、画面の縦横比に左右されにくい座標系を作ります。

uv = (position.xy * 2.0 - resolution) / min(width, height)

その後、centerY で中心を上下にずらし、viewScale で全体表示倍率を反映します。

渦巻き配置

ループ内では spiralT を 0 から 1 へ進め、角度と半径を計算します。 

let spiralT = fi / max(1.0, totalCount - 1.0);
let angle = spiralT * spiralTurns * tau + u.rotation;
let innerRadius = min(u.ringRadius, max(0.0, u.cloudSize * 0.28));
let radius = mix(innerRadius, u.ringRadius, spiralT);
let center = vec2f(cos(angle), sin(angle)) * radius;

spiralT が小さい雲は中心側、1 に近い雲は外周側に置かれます。 spiralTurns を増やすと、角度の進みが大きくなり、巻き数が増えます。

雲ごとのローカル座標

ピクセル座標から雲の中心を引き、雲の向きに合わせて回転し、サイズで割ります。 これで各雲パーツから見たローカル座標になります。 

var local = uv - center;

var orientAngle = angle;
if (u.orientation > 1.5) {
  orientAngle = 0.0;
} else if (u.orientation > 0.5) {
  let radialStep = max(0.0001, (u.ringRadius - innerRadius) / max(tau, tau * spiralTurns));
  orientAngle = angle + atan2(radius, radialStep);
}

local = rotate(local, -orientAngle);
local = vec2f(
  local.x / max(0.01, u.cloudSize * u.cloudAspect),
  local.y / max(0.01, u.cloudSize)
);
orientation 雲の向き
0 放射方向。配置角度に沿って雲を回します。
1 接線方向。渦巻きの進行方向に近い角度へ回します。
2 固定。雲の向きを回さず、全パーツ同じ向きにします。

雲ごとの位相

各雲の見た目は phase と phaseCycles で変わります。 phaseCycles が 1 なら、中心から外周までで位相が 1 周します。 

let instancePhase = u.phase + spiralT * tau * u.phaseCycles;
let cloudInk = phaseCloud(local, instancePhase);
ink = max(ink, cloudInk);

6. phaseCloud の詳細

phaseCloud は 1 個の雲パーツの中身を作る関数です。 ローカル座標を球面上の点として扱い、その球を位相角だけ回転させたあと、ノイズ空間へ投影します。

2D ローカル座標を球面に持ち上げる

let radius = length(p);
let sphereZ = sqrt(max(0.0, 1.0 - radius * radius));
let n = normalize(vec3f(p.x, p.y, sphereZ));

p.x, p.y を球面の X/Y とみなし、z = sqrt(1 - r^2) で半球上の点を作ります。 雲の外側では z が 0 に近づきます。

任意軸まわりの球面回転

let cp = cos(phase);
let sp = sin(phase);
let axis = sphereRotationAxis(u.sphereAxis.xyz);

let sphere = n * cp + cross(axis, n) * sp + axis * dot(axis, n) * (1.0 - cp);

これはロドリゲスの回転公式です。 phase が変わると、球面上の雲が指定軸まわりに回転したような入力座標になります。

球面から 2 種類のノイズ座標を作る

let surfaceA = vec2f(
  sphere.x + sphere.z * 0.64,
  sphere.y + sphere.z * 0.38
);
let surfaceB = vec2f(
  sphere.x * 0.72 - sphere.z * 0.46,
  sphere.y * 1.08 + sphere.z * 0.24
);

ひとつの投影だけだと単調になるため、係数の違う 2 つの座標系を使います。 sphere.z を混ぜることで、平面座標だけでは出にくい丸みのある変化が入ります。

swirl による歪み

let warp = fbm(surfaceA * 2.05 + seedOffset) - 0.5;
let cloudPoint = surfaceA * (2.0 + radius * 1.9)
  + surfaceB * 0.42
  + vec2f(u.swirl * 0.12 * warp, -u.swirl * 0.034 * sphere.y);

warp はノイズから作った歪み量です。 これを cloudPoint に加えることで、ノイズの等高線が曲がり、煙のような流れが出ます。

複数スケールの雲を合成

var ink = fbm(cloudPoint * 1.95 + seedOffset);
ink += 0.58 * fbm(cloudPoint * 4.4 - seedOffset + surfaceB * 0.18);
ink += 0.18 * fbm(cloudPoint * 7.8 + vec2f(surfaceA.y, -surfaceA.x) * 0.20);

低周波の大きな雲、中周波のうねり、高周波の細部を足しています。 係数 0.58 と 0.18 は、後段の細かい成分が主張しすぎないようにする重みです。

外縁フェードと白黒化

let fadeStart = clamp(u.outerFadeStart, 0.1, 1.2);
let fadeLength = clamp(u.softness, 0.02, 0.8);
let fadeSpeed = clamp(u.outerFadeSpeed, 0.25, 4.0);
let fadeProgress = smoothstep(fadeStart, fadeStart + fadeLength, radius);
let edgeFade = 1.0 - pow(fadeProgress, 1.0 / fadeSpeed);
let inkMask = smoothstep(0.38 + u.paper * 0.25, 1.08, ink * u.cloud);

return clamp(inkMask * edgeFade, 0.0, 0.98);

smoothstep によって、ノイズの連続値を墨の濃淡に変換します。 paper が大きいほど白が出にくくなり、cloud が大きいほど濃く出ます。 外縁では edgeFade によって自然に消えます。

7. 表示用フラグメントシェーダ

表示用シェーダは雲を生成しません。 生成済みの cloudTexture を、回転したテクスチャ座標で読みます。 

@fragment
fn fs(@builtin(position) position: vec4f) -> @location(0) vec4f {
  let minResolution = min(d.resolution.x, d.resolution.y);
  var uv = (position.xy * 2.0 - d.resolution) / minResolution;
  uv.y = -uv.y;

  let center = vec2f(0.0, d.centerY);
  let sourceUv = rotate(uv - center, -d.rotation) + center;
  var texCoord = sourceUv * minResolution / d.resolution;
  texCoord.y = -texCoord.y;
  texCoord = texCoord * 0.5 + vec2f(0.5, 0.5);

  let inside = step(0.0, texCoord.x)
    * step(texCoord.x, 1.0)
    * step(0.0, texCoord.y)
    * step(texCoord.y, 1.0);
  let sampled = textureSampleLevel(
    cloudTexture,
    cloudSampler,
    clamp(texCoord, vec2f(0.0), vec2f(1.0)),
    0.0
  );
  return vec4f(sampled.rgb * inside, 1.0);
}

ここでは逆回転を使っています。 出力ピクセルの位置を逆向きに回して、元テクスチャのどこを読むべきかを求めるためです。

sourceUv = rotate(uv - center, -rotation) + center

inside はサンプリング座標がテクスチャ範囲内かどうかのマスクです。 範囲外は黒になります。

8. なぜ二段構成にしているか

生成用フラグメントシェーダは、各ピクセルで最大 4096 個の雲候補をループし、 それぞれで複数回の fbm を呼びます。 これはかなり重い処理です。

一方、表示用シェーダはテクスチャを 1 回読むだけです。 自動回転中に毎フレーム生成し直すと負荷が高いため、現在の実装では生成済み画像を回転表示する構造になっています。

処理 主なコスト 実行タイミング
生成用シェーダ 雲配置ループ、球面位相、fbm ノイズ合成 Run、再生成、リサイズ、保存時
表示用シェーダ 座標回転、テクスチャサンプリング 通常表示、自動回転の各フレーム

9. パラメータ調整の読み方

触る値 シェーダ上の影響
count ループで配置される雲数が増減します。多いほど密になります。
spiralTurns angle = spiralT * spiralTurns * tau の進みが変わり、巻き数が変わります。
cloudSize ローカル座標を割る値が変わります。大きいほど雲パーツが広がります。
cloudAspect X 方向の割り算だけに効き、横長または縦長の雲になります。
phaseCycles 中心から外周に向けて、雲の位相が何周変化するかを決めます。
sphereAxisX/Y/Z 位相による球面回転の軸を変えます。模様の流れる方向が変わります。
swirl cloudPoint の歪みが増え、渦や煙の流れが強くなります。
