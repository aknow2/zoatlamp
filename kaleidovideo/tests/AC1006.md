# AC1006 — Phase 6: Download + Error Handling

## 前提条件
- `npm run dev` でアプリが起動していること
- ブラウザで `http://localhost:5173` にアクセスできること
- テスト用動画ファイル（mp4）が手元にあること

## テスト手順

### TC-006-01: PNG保存ボタンは生成前 disabled、生成後 enabled になる
1. ページを開く
2. 動画ファイルを選択してプレビューを表示する
3. 動画プレビュー上で基準点を指定する
4. `generateButton` をクリックする

**Expected:**
- 初期状態と生成前は `downloadButton` が disabled
- 生成後は `downloadButton` が enabled

### TC-006-02: PNG保存ボタンで PNG ダウンロードが実行される
1. TC-006-01 の手順で生成する
2. `downloadButton` をクリックする

**Expected:**
- Canvas から PNG blob が作成される
- ダウンロード用リンクがクリックされる
- ファイル名が `radial-slice-{frameCount}-{timestamp}.png` 形式になる

### TC-006-03: 動画未選択時に生成ボタンは disabled である
1. ページを開く

**Expected:**
- `generateButton` が disabled
- `downloadButton` が disabled

### TC-006-04: Canvas 初期化失敗時にエラーを表示する
1. 動画ファイルを選択してプレビューを表示する
2. 動画プレビュー上で基準点を指定する
3. output canvas の context 初期化失敗を発生させる
4. `generateButton` をクリックする

**Expected:**
- `Canvas を初期化できませんでした。` と表示される
- `downloadButton` は disabled のまま
