# AC1004 — Phase 4: Frame Extraction

## 前提条件
- `npm run dev` でアプリが起動していること
- ブラウザで `http://localhost:5173` にアクセスできること
- テスト用動画ファイル（mp4）が手元にあること

## テスト手順

### TC-004-01: 生成ボタンで指定フレーム数分のフレームが取得される
1. 動画ファイルを選択してプレビューを表示する
2. 動画プレビュー上で基準点を指定する
3. `frameCountInput` を `5` に設定する
4. `frameIntervalInput` を `0.1` に設定する
5. `generateButton` をクリックする

**Expected:**
- エラー表示が出ない
- `state.frames` 相当の抽出結果が `5` 件になる
- 各フレームに `index` と `time` が設定される

### TC-004-02: 基準点未指定では生成せずエラーを表示する
1. 動画ファイルを選択してプレビューを表示する
2. 基準点を指定しない
3. `generateButton` をクリックする

**Expected:**
- `動画上で切り出し基準点を指定してください。` と表示される
- フレーム抽出は実行されない

### TC-004-03: フレーム範囲が動画長を超える場合は生成せずエラーを表示する
1. 動画ファイルを選択してプレビューを表示する
2. 動画プレビュー上で基準点を指定する
3. `startSecondInput` と `frameCountInput` と `frameIntervalInput` を、最終フレーム時刻が動画時間を超える値に設定する
4. `generateButton` をクリックする

**Expected:**
- `指定したフレーム範囲が動画の長さを超えています。` と表示される
- フレーム抽出は実行されない

### TC-004-04: 入力値不正時に対応するバリデーションエラーを表示する
1. 動画ファイルを選択してプレビューを表示する
2. 動画プレビュー上で基準点を指定する
3. `frameCountInput` を `2` に設定して `generateButton` をクリックする
4. `frameIntervalInput`、`startSecondInput`、`sliceLengthInput`、`outputRadiusInput` も不正値で確認する

**Expected:**
- 各不正値に対応したエラーメッセージが表示される
- フレーム抽出は実行されない
