# AC1005 — Phase 5: Radial Rendering

## 前提条件
- `npm run dev` でアプリが起動していること
- ブラウザで `http://localhost:5173` にアクセスできること
- テスト用動画ファイル（mp4）が手元にあること

## テスト手順

### TC-005-01: 生成後に output canvas にラジアル画像が表示される
1. 動画ファイルを選択してプレビューを表示する
2. 動画プレビュー上で基準点を指定する
3. `frameCountInput` を `12` に設定する
4. `outputRadiusInput` を `128` に設定する
5. `generateButton` をクリックする

**Expected:**
- エラー表示が出ない
- `outputCanvas.width` と `outputCanvas.height` が `256` になる
- output canvas に透明でないピクセルが描画される

### TC-005-02: outputRadius 変更で output canvas サイズが変化する
1. TC-005-01 の手順で一度生成する
2. `outputRadiusInput` を `64` に変更する
3. `generateButton` をクリックする

**Expected:**
- `outputCanvas.width` と `outputCanvas.height` が `128` になる
- output canvas に生成結果が表示される

### TC-005-03: frameCount 変更で描画結果が変化する
1. 動画ファイルを選択してプレビューを表示する
2. 動画プレビュー上で基準点を指定する
3. `frameCountInput` を `12` に設定して生成する
4. `frameCountInput` を `24` に変更して生成する

**Expected:**
- 12フレーム生成時と24フレーム生成時で output canvas の描画内容が変化する
- エラー表示が出ない
