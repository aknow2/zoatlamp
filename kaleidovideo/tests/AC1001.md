# AC1001 — Phase 1: Project Setup

## 前提条件

- `npm run dev` でアプリが起動していること
- ブラウザで `http://localhost:5173`（または表示された URL）にアクセスできること

---

## テスト手順

### TC-001-01: 開発サーバーが起動し画面が表示される

1. `npm run dev` を実行する
2. ブラウザで表示された URL を開く

**Expected:**
- ページタイトルが「Video Radial Slice Generator」であること
- ヘッダーに「Video Radial Slice Generator」と表示されること
- 画面がエラーなく表示されること

---

### TC-001-02: 2カラムレイアウトが表示される

1. ページを開く

**Expected:**
- 左カラム（Settings Panel）が表示されること
- 右カラム（Preview Area）が表示されること

---

### TC-001-03: Settings Panel の全 input が存在する

1. 左カラムを確認する

**Expected:**
- 「動画ファイル」の file input が表示されること
- 「開始秒」の number input が表示されること（デフォルト: 0）
- 「フレーム数」の number input が表示されること（デフォルト: 24）
- 「フレーム間隔（秒）」の number input が表示されること（デフォルト: 0.033333）
- 「向き角度（度）」の number input が表示されること（デフォルト: -90）
- 「スライス長さ（px）」の number input が表示されること（デフォルト: 300）
- 「出力半径（px）」の number input が表示されること（デフォルト: 512）
- 各 input に label が付いていること

---

### TC-001-04: ボタンが表示される

1. 左カラムを確認する

**Expected:**
- 「生成」ボタンが表示されること
- 「PNG保存」ボタンが表示されること

---

### TC-001-05: キーボードでフォーム操作できる

1. Tab キーで各 input にフォーカスを移動する

**Expected:**
- Tab キーで各 input 間をフォーカス移動できること
- フォーカス時にアウトラインが表示されること
