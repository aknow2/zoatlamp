# AC1002 — Phase 2: Video Loading

## 前提条件

- `npm run dev` でアプリが起動していること
- ブラウザで `http://localhost:5173` にアクセスできること
- テスト用の動画ファイルが手元にあること（mp4 など）

---

## テスト手順

### TC-002-01: 動画ファイルを選択すると動画が表示される

1. ページを開く
2. 「動画ファイル」の file input をクリックし、ローカルの動画ファイルを選択する

**Expected:**
- `#sourceVideo` 要素に動画が表示される（最初のフレームが見える）
- エラーメッセージが表示されないこと

---

### TC-002-02: 動画のメタデータが取得される

1. TC-002-01 の操作後

**Expected:**
- ページに JavaScript エラーが発生しないこと（コンソールを確認）
- `state.videoMeta` に `duration`, `width`, `height` が格納されていること（コンソールログ等で確認、またはデバッガー）

---

### TC-002-03: 生成ボタンは動画未選択時に disabled になっている

1. ページを開いた直後（動画未選択の状態）

**Expected:**
- `#generateButton` が `disabled` 状態であること

---

### TC-002-04: 生成ボタンは動画選択後に enabled になる

1. 動画ファイルを選択する

**Expected:**
- `#generateButton` の `disabled` が解除されること

---

### TC-002-05: PNG保存ボタンは初期状態で disabled になっている

1. ページを開いた直後

**Expected:**
- `#downloadButton` が `disabled` 状態であること

---

### TC-002-06: 同じ動画を再選択しても正常に動作する

1. 動画ファイルを選択する
2. 再度同じ（または別の）動画ファイルを選択する

**Expected:**
- エラーが表示されないこと
- 動画プレビューが更新されること

---
