# AC1003 — Phase 3: Sample Point + Guide

## 前提条件
- `npm run dev` でアプリが起動していること
- ブラウザで `http://localhost:5173` にアクセスできること
- テスト用動画ファイル（mp4）が手元にあること

## テスト手順

### TC-003-01: 動画プレビュークリックで基準点が設定され、マーカーが表示される
1. 動画ファイルを選択してプレビューを表示する
2. 動画プレビュー（overlay）上の任意の位置をクリックする

**Expected:**
- クリック位置に基準点マーカーが表示される
- エラー表示が出ない

### TC-003-02: フレーム数変更で三角形頂点角度が変化する
1. 基準点を設定する
2. `frameCountInput` を `24` に設定した状態のガイド形状を確認する
3. `frameCountInput` を `12` に変更してガイド形状を確認する

**Expected:**
- `frameCount` 変更に応じて三角形の開き角（頂点角度）が変化する

### TC-003-03: 向き角度変更で三角形の向きが変化する
1. 基準点を設定する
2. `directionDegInput` を変更する（例: `-90` → `0`）

**Expected:**
- 三角形ガイドの向きが変化する

### TC-003-04: スライス長さ変更で三角形サイズが変化する
1. 基準点を設定する
2. `sliceLengthInput` を変更する（例: `300` → `150`）

**Expected:**
- 三角形ガイドの辺の長さが変化する

### TC-003-05: リサイズ後もクリック座標が実動画座標に変換されてガイド表示される
1. 動画プレビュー表示後、ウィンドウサイズを変更する
2. 動画プレビューをクリックして基準点を再設定する

**Expected:**
- リサイズ後でもクリック位置に基準点マーカーが表示される
- ガイド描画が破綻しない
