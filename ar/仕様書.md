# ロータリーエンコーダー付きモーター・ライト制御 仕様書

## 1. 概要

本システムは Arduino Leonardo を制御基板として使用し、ボタン付きロータリーエンコーダー、モーター、LED を制御する。

- ロータリーエンコーダーの回転でモーター用 MOSFET1 の PWM 値を変更する。
- エンコーダーの押しボタンでライト動作モードを切り替える。
- ライトが OFF の場合は、モーターも停止し、PWM 値変更を受け付けない。

## 2. ハードウェア構成

### 2.1 使用部品

- 制御基板: Arduino Leonardo
- 入力部品: ボタン付きロータリーエンコーダー x1
- 出力制御: MOSFET x2
- 負荷:
  - MOSFET1: モーター制御用
  - MOSFET2: DC12V 高輝度 LED 制御用

### 2.2 信号構成

既存スケッチ上で確定している入力ピンは以下とする。

- `PIN_CLK = 8`
- `PIN_DT = 12`
- `PIN_SW = A0`

出力ピンは以下とする。

- `PIN_MOTOR_PWM = 9`: MOSFET1 のゲートへ接続
- `PIN_LED_PWM = 10`: MOSFET2 のゲートへ接続

### 2.3 電気的前提

- ロータリーエンコーダーの CLK、DT、SW は `INPUT_PULLUP` で使用する。
- ボタン入力は Low アクティブとする。
- モーター制御は MOSFET1 への PWM 出力を前提とする。
- モーター用 MOSFET1 の PWM 値は 0 から 600 permille の範囲で管理する。
- 管理値が 600 permille に到達した場合、Arduino の PWM 出力値は最大値 `255` とする。
- LED は DC12V 電源で駆動する高輝度 LED を前提とする。
- LED はローサイド MOSFET により駆動し、PWM 制御に対応するものとする。
- LED の点灯、消灯、点滅は PWM 出力で制御する。

## 3. 機能仕様

### 3.1 ライトモード

ライトモードは以下の 3 状態を持つ。

1. `OFF`
2. `ON`
3. `BLINK`

押しボタンを短押しするたびに、ライトモードは次の順に遷移する。

`OFF -> ON -> BLINK -> ON`

押しボタンを 2 秒以上長押しした場合、現在のライトモードに関わらず `OFF` へ遷移する。

### 3.2 モーター制御

- ロータリーエンコーダーの 1 クリックは、ユーザーが指で感じる 1 ノッチ分の操作とする。
- ロータリーエンコーダーを時計方向に 1 クリック回した場合、モーター用 MOSFET1 の PWM 値を上げる。
- 現在の PWM 値が 60 permille 未満の場合は 200 permille 上げる。
- 現在の PWM 値が 60 permille 以上の場合は 1 permille 上げる。
- ロータリーエンコーダーを反時計方向に 1 クリック回した場合、モーター用 MOSFET1 の PWM 値を 1 permille 下げる。
- モーター用 MOSFET1 の PWM 値は 0 以上 600 permille 以下の範囲で管理する。
- 実装時の PWM 出力値は、管理している permille 値を Arduino の PWM 分解能に応じて換算する。
- 600 permille 未満では `permille * 255 / 1000` を丸めた値を出力し、600 permille 以上では `255` を出力する。

### 3.3 ライト OFF 時の制約

ライトモードが `OFF` の間は、以下を必須動作とする。

- LED は消灯する。
- モーター用 MOSFET1 の PWM 値は強制的に 0 permille にする。
- モーター出力は停止状態を維持する。
- ロータリーエンコーダーを回しても PWM 値変更を受け付けない。

### 3.4 ライト ON 時の動作

- LED を連続点灯する。
- 連続点灯時の LED PWM 出力値は `60` とする。
- ロータリーエンコーダーによるモーター用 MOSFET1 の PWM 値変更を許可する。

### 3.5 ライト BLINK 時の動作

- LED は点滅動作を行う。
- 点滅周期は `50ms` とする。
- 各周期における点灯時間は `5ms` とする。
- 消灯時間は `45ms` とする。
- デューティ比は `10%` とする。
- 点滅時の LED PWM 出力値は `108` とする。
- ロータリーエンコーダーによるモーター用 MOSFET1 の PWM 値変更を許可する。

## 4. 状態遷移仕様

### 4.1 ライトモード遷移

| 現在モード | ボタン短押し後 | LED状態 | MOSFET1 PWM 値変更 |
| --- | --- | --- | --- |
| OFF | ON | 連続点灯 | 可 |
| ON | BLINK | 50ms周期、5ms点灯 | 可 |
| BLINK | ON | 連続点灯 | 可 |

ボタンを 2 秒以上長押しした場合は、現在モードに関わらず `OFF` へ遷移する。

### 4.2 モーター用 MOSFET1 PWM 値遷移

- 現在モードが `ON` または `BLINK` の場合のみ、エンコーダー回転で PWM 値を更新する。
- 現在モードが `OFF` の場合、PWM 値は常に 0 permille を維持する。
- `ON` または `BLINK` から `OFF` へ遷移した時点で、保持している PWM 値は 0 permille にリセットする。
- `ON` と `BLINK` の間で遷移する場合、保持している PWM 値は変更せず、モーター速度を維持する。

## 5. タイミング仕様

### 5.1 ボタン入力

- ボタン入力はチャタリング対策を行うこと。
- 既存スケッチに合わせ、デバウンス時間の初期値は `30ms` を基準とする。
- 2 秒以上の長押しは短押しとして扱わず、長押し成立時点で `OFF` へ遷移する。

### 5.2 エンコーダー入力

- CLK 信号の下降エッジを契機に回転方向を判定する。
- DT 信号との位相差から時計方向 / 反時計方向を判定する。
- PWM 値の更新は 1 クリックごとに 1 回だけ行う。

### 5.3 LED 点滅

- `millis()` ベースのノンブロッキング制御を推奨する。
- `delay()` によってエンコーダー入力やボタン入力の取りこぼしが発生しないようにする。

## 6. 制御パラメータ

以下の項目は実装時の調整パラメータとする。

- モーター用 MOSFET1 の PWM 値の初期値: `0 permille`
- エンコーダー 1 クリックあたりの PWM 値増減量
  - 上昇時かつ現在値が 60 permille 未満: `200 permille`
  - 上記以外: `1 permille`
- モーター用 MOSFET1 の PWM 値の最大値: `600 permille`
- モーター制御用 PWM 出力ピン: `9`
- LED 制御用出力ピン: `10`

## 7. 実装上の補足

- Leonardo を使用するため、シリアルデバッグを行う場合は USB シリアル接続待ちを考慮する。
- モーター駆動回路には逆起電力対策を含めること。
- モーターと LED は MOSFET を介して駆動し、Arduino の I/O ピンで直接負荷を駆動しないこと。

## 8. 受け入れ条件

以下を満たした場合、本仕様を満足したものとする。

1. 電源投入後、初期ライトモードが `OFF` である。
2. 初期状態で LED は消灯し、モーターは停止している。
3. `OFF` 状態でエンコーダーを回してもモーター用 MOSFET1 の PWM 値が変化しない。
4. ボタンを 1 回短押しすると `ON` へ遷移し、LED が連続点灯する。
5. `ON` 状態で PWM 値が 60 permille 未満の時に時計方向へ 1 クリック回すと、モーター用 MOSFET1 の PWM 値が 200 permille 上がる。
6. `ON` 状態で反時計方向に 1 クリック回すと、モーター用 MOSFET1 の PWM 値が 1 permille 下がる。
7. ボタンをさらに 1 回短押しすると `BLINK` へ遷移し、LED が 50ms周期、点灯時間 5ms で点滅する。
8. `BLINK` 状態でもエンコーダーによるモーター用 MOSFET1 の PWM 値変更が可能である。
9. `BLINK` 状態からボタンを短押しすると `ON` に戻り、LED が連続点灯し、モーター用 MOSFET1 の PWM 値は維持される。
10. ボタンを 2 秒以上長押しすると `OFF` に戻り、LED 消灯かつモーター用 MOSFET1 の PWM 値が 0 permille になる。
11. `OFF` に戻った後は、エンコーダー操作による PWM 値変更が無効である。
